Setup

EvalAssist runs locally with Python 3.10 or later. No database, no external API keys, no cloud account.

1. Install dependencies

pip install -r requirements.txt

This installs Flask, scikit-learn, pypdf, python-docx, and pytest.

2. Start the server

python app.py

3. Open in your browser

http://127.0.0.1:5000

4. Run tests

pytest tests/test_core.py -v

API reference

All API endpoints accept and return JSON. CORS is not configured; the API is intended for localhost use only.

POST /api/evaluate

Evaluate a student's answer against a rubric.

Request body

{
  "answer":    "BFS uses a queue to explore nodes level by level…",
  "rubric":    "Define BFS and explain its purpose\nDescribe the queue data structure",
  "max_marks": 10,
  "mode":      "passage",
  "label":     "Optional label",
  "question":  "Optional question text"
}
FieldTypeRequiredNotes
answerstringYesPlain text of the student's answer
rubricstringNoOne criterion per line; blank = 4 default BFS criteria
max_marksnumberNo1–100; default 10
modestringNo"passage" (default) or "whole"
labelstringNoFree-text label for session history
questionstringNoQuestion text for history display

Response (200 OK)

{
  "criteria": [
    {
      "criterion":       "Define BFS and explain its purpose",
      "S":               0.4821,
      "K":               0.5714,
      "R":               0.5135,
      "marks_available": 5.0,
      "marks_suggested": 2.57,
      "band":            "Partial coverage",
      "feedback":        "Partial coverage. Consider addressing: graph, traversal.",
      "matched_words":   ["breadth", "search", "queue"],
      "missing_words":   ["graph", "traversal", "level"],
      "matched_sentence": "BFS uses a queue to explore nodes level by level."
    }
  ],
  "total_marks_available": 10,
  "total_marks_suggested": 5.14,
  "overall_R":             0.5135
}

Error response (400)

{ "error": "The answer field is empty. Please paste or upload an answer before evaluating." }

POST /api/evaluate/upload

Extract text from a file upload (multipart/form-data). Returns the extracted text so the client can display it before submitting.

// Response
{ "text": "Extracted plain text from the file…" }

GET /api/selftest

Run the built-in self-checks and return pass/fail with timing.

{
  "all_pass": true,
  "checks": [
    { "name": "Empty answer raises error", "status": "pass", "ms": 0.4 },
    …
  ]
}

POST /api/rules

Fire the rule engine with given completeness and correctness values.

// Request
{ "completeness": 0.8, "correctness": 0.9 }

// Response
{
  "fired_rule":  "R1",
  "conclusion":  "High provisional score – strong evidence on both dimensions.",
  "trace":       ["Inputs: completeness=0.80, correctness=0.90", "R1 FIRED: …"],
  "completeness": 0.8,
  "correctness":  0.9
}

POST /api/search

Run a search algorithm on the evaluation state graph.

// Request: { "algorithm": "bfs" }  (bfs | dfs | ids | greedy | astar)
// Response: { "algorithm": "BFS", "path": ["S0","S1","S4","S6"], "found": true, … }

Troubleshooting

Import errors on startup

Run pip install -r requirements.txt again. If using a virtual environment, ensure it is activated before running python app.py.

PDF shows "almost no text"

The PDF is likely scanned or image-based. Copy the text manually and paste it into the answer textarea. OCR is not supported.

Score seems unexpectedly low

TF-IDF does not understand synonyms or paraphrases. If the answer is correct but uses different vocabulary to the rubric criterion, the score will be lower than expected. This is a known limitation — review the evidence chips and adjust the mark in the teacher review panel.

Port 5000 already in use

python app.py --port 5001   # or edit app.py: port=5001

pytest: ModuleNotFoundError

Run pytest from the project root directory (the folder containing app.py):

cd path/to/evalassist
pytest tests/test_core.py -v

Responsible use reminder

  • Use anonymised data — no names or IDs in uploaded files.
  • Every provisional mark must be approved by a teacher before use.
  • Do not use for high-stakes exams without independent human review.
